# Práctica: Taller práctico de diseño de prompts aplicados al día a día del área de calidad.

### Duración Estimada
90 minutos

---

### Descripción de la Actividad
En este laboratorio práctico, asumirás el rol de un Ingeniero Senior de Mejora Continua en Cerámicas del Norte. Aprenderás a dominar la ingeniería de prompts en Microsoft 365 Copilot Chat para diseñar indicadores clave de desempeño (KPIs), automatizar análisis operativos, generar activos visuales para la gestión visual de planta y estructurar guiones de presentación ejecutiva.

---

## Objetivos del Laboratorio
- Construir e iterar un prompt estructurado bajo la técnica RTF (Rol, Tarea, Formato) enfocado en KPIs de calidad.
- Ejecutar el prompt generado para obtener un análisis operacional listo para Microsoft Excel.
- Diseñar una instrucción para la creación de imágenes de gestión visual orientadas a Microsoft PowerPoint.
- Ejecutar el prompt gráfico creado en Copilot Designer para obtener el render de señalética de planta.
- Documentar estándares operativos en Microsoft Word y redactar comunicados de desviación para Microsoft Outlook.
- Sintetizar los resultados técnicos en una estructura de diapositivas para comités directivos en Microsoft PowerPoint.

---

## Prerrequisitos
- Acceso a Microsoft 365 Copilot Chat (Enterprise / Web).

---

### Fase 1: Ingeniería de Prompts — Creación del Prompt de KPIs de Calidad

**Herramienta objetivo:** Copilot Chat (Diseño de Instrucción)

Aprende a estructurar una instrucción directa usando la fórmula **Rol + Tarea + Formato**. Copia el siguiente comando en Copilot Chat para que actúe como tu instructor y te redacte el prompt que usarás en la siguiente fase.

```
Actúa como un experto en Ingeniería de Prompts para calidad industrial.

Genera una instrucción directa y concisa (máximo 4 líneas) para que un Ingeniero de Calidad de Cerámicas del Norte le solicite a Copilot calcular 4 KPIs de una línea de porcelánicos (Scrap %, OEE, DPMO y Reingreso) y los entregue en una tabla Markdown estructurada para copiar a Excel.
```

---

### Fase 2: Ejecución del Prompt Generado para Excel

**Herramienta objetivo:** Copilot Chat para estructuración en Microsoft Excel (Tabla Markdown)

**Instrucción para el estudiante:**
Copia el prompt exacto de 4 líneas que Copilot acaba de redactarte en la Fase 1, pégalo como un nuevo mensaje dentro del chat y ejecútalo. 

*(Al ejecutarlo, Copilot calculará los datos operativos del turno y te entregará directamente la tabla Markdown estructurada con las columnas de KPIs, metas y acciones correctivas, lista para que la copies y pegues en Microsoft Excel).*

---

### Fase 3: Ingeniería de Prompts Visuales — Creación del Prompt para Señalética

**Herramienta objetivo:** Copilot Chat (Diseño de Instrucción de Imagen)

Aprende a construir órdenes de imagen claras para la gestión visual de planta. Copia la siguiente instrucción en Copilot Chat para que construya la orden gráfica.

```
Actúa como un Diseñador Visual Lean. Redacta una instrucción de imagen corta (máximo 3 líneas) lista para copiar y pegar en Copilot Designer. Debe solicitar una fotografía fotorrealista de un inspector de calidad midiendo con un calibrador una pieza de porcelánico en una planta moderna, con enfoque en precisión y código de colores industrial.
```

---

### Fase 4: Ejecución del Prompt Visual en Copilot Designer

**Herramienta objetivo:** Copilot Chat / Copilot Designer (Generador de Imágenes)

**Instrucción para el estudiante:**
Copia la instrucción de imagen de 3 líneas que Copilot te entregó en la Fase 3, pégala en el chat y ejecútala.

*(Al enviarla, Copilot Designer procesará el texto y generará de forma inmediata la imagen fotorrealista del inspector en planta, lista para insertarse en una presentación de Microsoft PowerPoint).*

---

### Fase 5: Redacción del Estándar Operativo de Calidad

**Herramienta objetivo:** Copilot Chat para documentación en Microsoft Word

Pide a Copilot Chat que consolide los KPIs calculados en la Fase 2 dentro de un estándar de desempeño operativo adaptado para Microsoft Word.

```
Actúa como Coordinador de Mejora Continua. Con base en los KPIs calculados previamente (Scrap, OEE, DPMO y Reingreso), redacta un procedimiento corto para Microsoft Word organizado en 3 secciones:
1. Objetivo y Alcance del Monitoreo.
2. Fórmulas de Cálculo y Criterios de Aceptación.
3. Plan de Escalamiento cuando la Tasa de Scrap supere la meta del 2.5%.
```

---

### Fase 6: Comunicación de Desviación de KPI por Correo

**Herramienta objetivo:** Copilot Chat / Preparación para Microsoft Outlook

Utiliza Copilot Chat para transformar la alerta del KPI crítico en un correo de acción rápida listo para redactarse en Microsoft Outlook.

```
Actúa como Ingeniero de Procesos. Redacta un correo breve para Microsoft Outlook dirigido al equipo de planta reportando que la Tasa de Scrap alcanzó un 4.2% en el turno nocturno por alabeo. Incluye asunto urgente, causa principal y cita a reunión Kaizen de 10 minutos en la línea.
```

---

### Fase 7: Estructuración de la Presentación Ejecutiva para el Comité de Calidad

**Herramienta objetivo:** Copilot Chat para guion visual en Microsoft PowerPoint

Utiliza Copilot Chat para sintetizar los hallazgos operacionales y las acciones de contención en un esquema de diapositivas listo para trasladar a Microsoft PowerPoint.

```
Actúa como Gerente de Calidad y Mejora Continua. Con base en los indicadores analizados, la imagen de señalética generada y la alerta de desviación por alabeo, redacta la estructura de contenido para una presentación ejecutiva de 3 diapositivas en Microsoft PowerPoint:

1. Diapositiva 1 (Diagnóstico): Resumen ejecutivo de los KPIs del turno e imagen conceptual sugerida.
2. Diapositiva 2 (Desviación Crítica): Análisis del incremento del Scrap al 4.2% por alabeo y su impacto económico.
3. Diapositiva 3 (Plan de Acción): 3 compromisos clave aprobados en la reunión Kaizen y fechas de resolución.

Para cada diapositiva especifica título, 3 puntos clave en formato de viñeta corta y la descripción del elemento visual a incluir.
```

---

### Reto Práctico: Diseño Autónomo de Prompts por Desviación de Colorimetría

**Herramienta objetivo:** Copilot Chat (Resolución Autónoma)

**Escenario de Desafío:**
La línea de esmaltado reporta un problema crítico de "destonificación" (variación del tono de color) en la colección de porcelánicos. El cliente de un proyecto comercial rechazó un lote de 2,000 m². Necesitas diseñar y ejecutar tus propios prompts breves para resolver la situación sin usar plantillas.

**Tu Desafío:**
1. Diseña y ejecuta un primer prompt conciso para que Copilot te genere una tabla Markdown con las 3 causas probables (viscosidad, densidad y temperatura) y sus ajustes para Excel.
2. Diseña y ejecuta un segundo prompt de 2 líneas para generar una carta técnica de disculpa y reprogramación para el cliente por Outlook.

Pistas para construir tus prompts:
- Mantenlos de máximo 3 líneas cada uno.
- Asigna el rol técnico adecuado (Ingeniero Químico Ceramista).
- Especifica claramente la salida (Tabla Markdown en la parte 1, formato de correo en la parte 2).

---

## Conceptos Clave para Recordar

- Metodología en Dos Pasos (Diseño y Ejecución): Usar a Copilot primero para construir la instrucción garantiza que la salida técnica o visual posterior cumpla con todos los estándares requeridos.
- Concisión y Claridad: Un prompt breve enfocado en Rol, Tarea y Formato reduce respuestas ambiguas y acelera el trabajo operacional.
- Flujo Documental Completo: La información procesada evoluciona de datos crudos (Excel) a documentación normativa (Word), alertas operativas (Outlook) y reportes ejecutivos (PowerPoint).

---

## Resultado Esperado del Estudiante

Al finalizar los 90 minutos del laboratorio, el estudiante habrá generado en Copilot Chat:
1. El prompt corto diseñado para la medición de KPIs.
2. La tabla de KPIs calculada mediante el prompt de la Fase 1 y lista para pegar en Microsoft Excel.
3. La instrucción de texto para generar el afiche visual de inspección de calidad.
4. El render fotorrealista generado por Copilot Designer a partir de la instrucción de la Fase 3.
5. El procedimiento operativo redactado para Microsoft Word.
6. El correo de alerta de desviación listo para Microsoft Outlook.
7. El guion de 3 diapositivas estructurado para Microsoft PowerPoint.
8. Los dos prompts propios resueltos para la contingencia de destonificación.
