# Práctica: Desarrollo de una matriz de control de riesgos y guía de uso responsable para el uso corporativo de Copilot.

### Duración Estimada
30 minutos

---

### Descripción de la Actividad
En esta sesión de 30 minutos, asumirás el rol de Oficial de Gobierno de Datos en Cerámicas del Norte. Evaluarás los riesgos críticos del uso de Copilot, generarás una matriz de control para Microsoft Excel, diseñarás la instrucción para una infografía visual de concientización y redactarás la política express de uso responsable para la empresa.

---

## Objetivos del Laboratorio
- Identificar riesgos clave en el uso de IA (fuga de datos y alucinaciones).
- Crear una Matriz de Riesgos en tabla Markdown para Microsoft Excel.
- Diseñar y generar la instrucción para una infografía visual de concientización en Copilot Designer.
- Redactar una Política Express de Uso Responsable para Microsoft Word.

---

## Prerrequisitos
- Acceso a Microsoft 365 Copilot Chat y Copilot Designer.

---

### Fase 1: Matriz de Control de Riesgos para Excel

**Herramienta objetivo:** Copilot Chat (Estructuración para Excel)

Genera la matriz con los 3 riesgos principales de IA para copiar directamente a Microsoft Excel.

```
Actúa como Oficial de Seguridad de la Información en Cerámicas del Norte.

Genera una tabla Markdown lista para copiar a Microsoft Excel con los 3 riesgos principales de usar Copilot en planta: Fuga de Datos Confidenciales, Alucinación de Datos Técnicos y Permisos No Autorizados.

Usa exactamente estas columnas:
| ID Riesgo | Riesgo | Nivel de Impacto | Medida de Mitigación | Responsable |

```

---

### Fase 2: Creación y Ejecución de la Infografía en Copilot Designer

**Herramienta objetivo:** Copilot Chat / Copilot Designer

Diseña la instrucción visual y ejecútala inmediatamente en Copilot Designer para obtener el póster de gobierno de IA.

```
Actúa como Diseñador Corporativo. Redacta una instrucción de imagen de máximo 3 líneas lista para ejecutar en Copilot Designer. Debe solicitar una infografía vectorial limpia sobre "Uso Seguro de Copilot", con 3 iconos: un candado (Protección de Datos), una lupa (Verificación de Resultados) y un escudo (Cero Datos Confidenciales). Usar colores corporativos azul y verde.

```

**Instrucción para el estudiante:**
Copia la instrucción de 3 líneas obtenida, pégala en el chat y ejecútala en Copilot Designer para generar el póster de concientización.

---

### Fase 3: Política Express de Uso Responsable para Word

**Herramienta objetivo:** Copilot Chat para Microsoft Word

Redacta las reglas corporativas clave para el uso de Copilot en la empresa.

```
Actúa como Director de Cumplimiento. Con base en la matriz de riesgos, redacta una Política Express de Uso de Copilot para Microsoft Word en 3 puntos directos:
1. Qué datos están prohibidos ingresar a Copilot.
2. Regla del "Humano al Mando": obligación de verificar fórmulas y datos técnicos.
3. Responsabilidad del usuario sobre la información generada.

```

---

### Reto Práctico: Regla Antialucinación

**Herramienta objetivo:** Copilot Chat (Resolución Autónoma)

**Escenario de Desafío:**
Un usuario envió un dato técnico no verificado generado por Copilot que causó un error en la configuración del horno.

**Tu Desafío:**
Escribe y ejecuta un prompt de máximo 2 líneas para que Copilot redacte un checklist de 3 pasos rápidos de verificación humana antes de enviar cualquier reporte técnico.

---

## Conceptos Clave para Recordar

- Humano al Mando: Todo dato o cálculo generado por IA debe ser verificado por un especialista antes de aplicarse en planta.
- Protección de Prompts: Nunca debes ingresar secretos industriales o datos personales en el chat de IA.

---

## Resultado Esperado del Estudiante

Al finalizar el estudiante habrá generado:
1. La tabla de 3 riesgos clave para Microsoft Excel.
2. La instrucción de imagen para la infografía corporativa.
3. La Política Express de Uso Responsable para Microsoft Word.
4. El checklist de verificación humana resuelto en el reto.
